# ADR（Architecture Decision Records）

> 目录用途：记录重要架构决策及其上下文、决策、后果
> 何时读取：引入新边界约束、变更架构规范时
> 是否可作为当前实现依据：是（经讨论接受的决策）

## 文件命名

ADR 编号从 0001 开始：`0001-<short-description>.md`

## 标准格式

每个 ADR 必须包含：
- **状态**：Proposed / Accepted / Rejected
- **上下文**：问题背景、约束条件
- **决策**：具体方案
- **后果**：实施后果、替代方案（如有拒绝）
