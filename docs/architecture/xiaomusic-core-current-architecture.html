标准播放控制链

WebUI / Caller→Public API→PlaybackFacade→PlaybackCoordinator→TransportRouter→XiaoMusicDevice→Mina / MiIO→Speaker
  • Coordinator 负责来源解析、投递计划与 transport 选择，不拥有设备队列。
  • direct → proxy fallback 在同一个设备 worker 中完成；同步响应只表示 accepted。
  • STOP / PAUSE 是 barrier，普通待处理意图按 latest-wins 收敛。

图例与边界

API / 物理接口 播放编排 Runtime / Auth 状态 / 事实 任务 / 策略
  • MusicLibrary 保存歌单成员事实。
  • RuntimeState 保存设备播放生命周期。
  • TaskRegistry 统一持有播放相关异步任务。
